# Repository instructions

- Run the relevant unit and smoke tests before pushing an update.
- Every functional update pushed to `main` must receive a new GitHub Release.
- Create and push the next semantic-version tag (`vX.Y.Z`) after the update; use a patch bump unless the change clearly requires a minor or major bump.
- Do not create or push a release tag when validation fails.
- Keep OpenAI Codex credited in the README when Codex materially contributes code, review, or tests.
